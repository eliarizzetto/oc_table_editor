Editing tips
  • Click on any text to edit it
  • Hover on cells to see action buttons (add, clear, delete)
  • Use + add to append a new value to multi-value fields
  • Use + row at the bottom of every page to add rows
  • Grey background = edited item
  • Green background = added item or row
  • Red strikethrough = deleted data (always visible as ghosts)
  • Underline = has validation issues
  • Click colored square to filter by issue
  • Cells are reduced by default: one line per valid cell; in cells with issues, all invalid items are shown in full and valid ones are hidden behind an ellipsis
  • Use the Expand cells button above each table (each table expands independently), or the ▸/▾ chevron next to the row number, to show full cell contents
  • By default only rows with errors/warnings or changes are shown; Show all rows reveals the rest
  • Show Changes Only = view only edited, added and deleted data
  • When both a metadata and a citations table are loaded, each table has its own filters, pager and + row button — they work independently
  • Undo/Redo (sidebar buttons or Ctrl+Z / Ctrl+Y) works across both tables: the most recent change anywhere is always undone first, and the view jumps to what was undone/redone
  • Each table is paginated (25 rows per page)
  • Re-validate after editing
Understanding the validation view

The parts of the table that did not validate are marked by an underlining and immediately followed by a coloured square. Data involving an Error is marked by a red underline, data involving a Warning is marked by an orange underline.

Each single coloured square represents the association between an Error/Warning and a single piece of data. Squares of the same colour all represent the same error instance.

To get an explanation of an Error/Warning, hover with the mouse cursor over any of the squares that represent it. If you click on it, the table shows only the data involved in that Error/Warning.
